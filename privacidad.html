Política de privacidad

METEO SENÉS AUTO

1. Finalidad de la aplicación

METEO SENÉS AUTO es una herramienta privada utilizada por el responsable del canal METEO SENÉS para automatizar tareas relacionadas con sus emisiones meteorológicas en YouTube.

La aplicación utiliza la API de YouTube para preparar y gestionar emisiones en directo, incluyendo la creación, consulta, configuración y vinculación de emisiones y transmisiones del canal.

2. Datos de Google y YouTube utilizados

METEO SENÉS AUTO accede únicamente a los datos necesarios para realizar las funciones autorizadas mediante OAuth 2.0.

Entre ellos pueden encontrarse:

  • Información básica del canal de YouTube autorizado.
  • Información y configuración de emisiones en directo.
  • Información y configuración de transmisiones de vídeo.
  • Datos necesarios para crear, consultar, actualizar y vincular emisiones.

La aplicación no solicita ni almacena la contraseña de la cuenta de Google.

3. Uso de los datos

Los datos obtenidos a través de las APIs de Google se utilizan exclusivamente para automatizar la gestión de las emisiones del canal METEO SENÉS.

No se utilizan para publicidad, elaboración de perfiles, venta de datos ni otros fines distintos de la funcionalidad descrita.

4. Almacenamiento y seguridad

Las credenciales de autorización OAuth necesarias para el funcionamiento de la herramienta se almacenan localmente en el ordenador privado del responsable de METEO SENÉS.

No existe una base de datos pública de usuarios ni se almacenan credenciales OAuth en esta página web.

5. Cesión de datos a terceros

METEO SENÉS AUTO no vende, alquila ni comparte los datos obtenidos mediante las APIs de Google con terceros.

6. Conservación y revocación

La autorización se conserva mientras sea necesaria para el funcionamiento de la automatización. El acceso puede revocarse en cualquier momento desde la configuración de seguridad de la Cuenta de Google autorizada.

Las credenciales locales también pueden eliminarse directamente del ordenador donde funciona la aplicación.

7. Política de datos de Google

El uso que METEO SENÉS AUTO realiza de la información recibida de las APIs de Google se ajusta a la Política de Datos de Usuario de los Servicios de APIs de Google, incluidos sus requisitos de Uso Limitado.

8. Contacto

Para consultas relacionadas con esta política de privacidad puede utilizarse el mismo correo electrónico de asistencia indicado en la pantalla de autorización de METEO SENÉS AUTO.
